# AI Assistant - Writing & Coding Helper

A web-based AI assistant that helps with both writing and coding tasks. Built using OpenRouter API to access various AI models.

## Features

- **Dual Mode**: Switch between Writing and Coding assistance
- **Multiple AI Models**: 
  - DeepSeek Chat
  - Mistral 7B
  - Llama 2 13B
  - OpenChat 7B
  - Nous Hermes 13B
- **Code Highlighting**: Syntax highlighting for multiple programming languages
- **Usage Tracking**: Track remaining free uses for each model
- **Responsive Design**: Works on both desktop and mobile devices

## Setup

1. Clone the repository
2. Add your OpenRouter API key in the `script.js` file
3. Open `index.html` in a browser or deploy to a web server

## Usage

1. Select mode (Writing/Coding)
2. Choose an AI model from the dropdown
3. For coding, select a programming language
4. Enter your prompt/question
5. Click Generate to get the response

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Prism.js for syntax highlighting
- OpenRouter API for AI models
